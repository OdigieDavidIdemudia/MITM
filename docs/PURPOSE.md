## Responsible disclosure
If you discover a vulnerability, please disclose it responsibly:
1. Do not publicly share before a fix is available.
2. Contact the project maintainer directly.
3. Allow reasonable time for a patch.

## Questions?
Before using this project, ask yourself:
- Do I own this system?
- Do I have explicit written permission?
- Is this activity legal in my jurisdiction?

If the answer to any of these is "no," do not proceed.
