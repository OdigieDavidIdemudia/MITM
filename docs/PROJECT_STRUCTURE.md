# Project structure

This repository is organized around experimental security research.

## Layout
```text
.
├── README.md
├── LICENSE
├── .gitignore
├── docs/
│   ├── PURPOSE.md           # Ethical guidelines and intended use
│   ├── ARCHITECTURE.md      # Technical implementation
│   └── SETUP.md             # How to run (authorized only)
├── src/
│   └── [implementation files]
├── examples/
│   └── [usage examples]
└── .github/
```

## Key principles
- **Legal compliance**: This project is for authorized testing only.
- **Clear documentation**: Purpose, scope, and limitations are clearly documented.
- **Ethical use**: All users must acknowledge legal and ethical responsibilities.
